有自己电脑的
AI 队友 AI teammates
with a computer
of their own

创建一个 Bot，交给它一份职责。它会在你的机器上，或在远程沙箱里，把这件事一直做下去——重启也不丢掉。该由你拍板的动作，会先停下来等批准。 Create a bot, give it a job, and it keeps working on that job across restarts — on your machine or a remote sandbox — and it stops for the actions that matter.

参照 Cursor 的 Grok Bot 而做的自托管开源实现。MIT 许可。 A self-hosted, open-source take on Cursor's Grok Bot. MIT licensed.

01

一台电脑，一份职责，一条要问你的边界 A computer, a job, and a line it has to ask about

每个 Bot 是一位持久的队友：自己的工作区、自己的对话、自己的权限。下面这些都是现在代码里的行为。 Each bot is a persistent teammate: its own workspace, its own thread, its own permission mode. Everything below is behavior that is in the code today.

01

一个 Bot，一份工作A bot per job

给它名字、一张脸、一段职责。工作区、对话记录和权限模式都是它自己的。一轮工作会留下来，进程重启也不会丢掉。 Name it, pick a face, say what it is for. The workspace, the history, and the permission mode belong to that bot. A run survives a process restart.

02

一台自己的电脑A computer of its own

bash、read、write、edit、ls 跑在沙箱里：Docker 容器，或仅供开发的本机。换一个目标就是换一台机器，那边的工作区不会跟着走。 bash, read, write, edit, and ls run in a sandbox: a Docker container, or — for development only — your own machine. Switching targets is a config change. The workspace on each target stays where it is.

03

审批，不是信任Approval, not trust

每次工具调用分成只读、写入、外部。按这个 Bot 的模式决定要不要先问你。额外规则只能收紧模式已经允许的事，不能放宽。 Every tool call is classified read, write, or external, and held for approval according to that bot's mode. Extra rules may only tighten what a mode allows. They never loosen it.

04

出网白名单An egress allowlist

Docker 驱动可以把沙箱放进 --internal 网络，只让桥接代理放行名单上的地址。MCP 是另一条出口，只有打开 applyToMcp 才受同一份名单约束。 The Docker driver can put a sandbox on an --internal network behind a bridging proxy, so only an allowlist gets out. MCP is a separate egress path, and it is only covered when applyToMcp is set.

05

例行，它自己排Routines it schedules

跟它说把这件事排进每天的固定日程，它会自己建一条例行。你看到一份可以关掉的列表。日程是几点、哪几天，不是假装精确到分钟的 cron。 Ask for something regularly and the bot schedules it itself. You get a list you can switch off. The schedule is a time of day and which days — not a cron that pretends to be exact to the minute.

06

交给同事，或拉个小组Handoff, or a group

一个 Bot 可以把活异步交给另一个。接收方仍走自己的审批，转交借不走权限；循环会被拒绝，链也有深度上限。两到六个 Bot 还可以共享小组对话，用 @名字 点名。 A bot can hand work to another asynchronously. The receiver keeps its own gate — delegation does not borrow permissions. Cycles are refused, and a chain has a depth limit. Two to six bots can also share a group chat, addressed with @name.

07

Web、Mac、手机Web, Mac, and a phone

同一套界面：浏览器、macOS 桌面应用，以及局域网里的手机。手机用同一枚令牌。pnpm lan 才会把端口绑出本机，终端里会打出配对地址。 The same UI: a browser, a macOS desktop app, and your phone on the LAN, with the same token. pnpm lan is what binds the port off localhost, and the terminal prints a pairing URL.

08

MCP

用 mcp.json 接上 MCP server。没有列进 readOnlyTools 的工具，默认按需要审批处理。 Connect MCP servers from mcp.json. Tools that are not listed in readOnlyTools need approval by default.

A bot in full mode runs commands on that machine, so do not leave it bound on a network you do not control. The server says this in the log when it starts.

05

沙箱、审批、出网 Sandbox, approval, egress

三道是分开的。沙箱决定命令跑在哪，审批决定要不要先问你，白名单决定沙箱那台电脑能连去哪。混成一件事，就会漏。 The three are separate. The sandbox is where a command runs, the gate is whether it has to ask, and the allowlist is where that computer may connect. Treating them as one perimeter is how a hole appears.

沙箱Sandbox

  • Docker：这台机器上的，或经 SSH、Docker context 连到的远程守护进程。Docker, on this machine or a remote daemon reached over SSH or a Docker context.
  • local：跑在编排进程那台主机上，没有隔离。只为开发而设。local runs on the orchestrator host with no isolation. Development only.
  • 每个 Bot 选一个目标。换目标不会把文件、登录态和装过的包带过去。Each bot picks a target. Switching does not take files, logins, or installed packages with it.

审批Approval

  • 这是规则引擎，不是写在提示词里的一句话。模型可以说服人，说不服这个函数。A rule engine, not a line in the prompt. A model can be talked out of an instruction. It cannot talk its way past this function.
  • 更严的一边赢。成员规则不能把团队规则放宽。Stricter wins. Member rules cannot loosen what team rules allow.
  • 转交给另一个 Bot 时，接收方仍用自己的门。When work is handed to another bot, the receiver's own gate still applies.

出网Egress

  • 只由 Docker 驱动执行。local 没有网络控制。Enforced by the Docker driver. The local driver has no network control.
  • stdio MCP 跑在宿主机上，不在沙箱网络里，这份策略盖不住它们自己连出去的地址。stdio MCP servers run on the host, outside the sandbox network. This policy does not cover what they connect to.
  • 远程 MCP 从编排进程拨号。只有 applyToMcp 为真时才用同一份名单。Remote MCP is dialed from the orchestrator. It uses the same list only when applyToMcp is true.

06

已知的界限 Known limits

这些写在 README 和实现里，不是路线图。 These are in the README and in the implementation. They are not a roadmap.

本机沙箱安全吗？Is the local sandbox safe?

local 驱动没有任何隔离，而且要 SANDBOX_ALLOW_LOCAL=1 才肯启动。它只适合开发。隔离用 Docker。 The local driver provides no isolation at all, and it will not start unless SANDBOX_ALLOW_LOCAL=1. It is for development. Docker is the isolated driver.

能多用户一起部署吗？Can several people share one deployment?

沙箱的生命周期是按所有者算的。多用户部署还需要这套模型之外的工作。 Sandbox lifecycle is per-owner. A multi-user deployment needs work beyond this.

能中途打断一条正在跑的命令吗？Can a running command be interrupted?

Sandbox.exec 接受超时，但没有 AbortSignal。正在跑的命令不能被打断，只能等它结束或超时。回合预算的做法是放弃这次会话，而不是卡在这条命令上。 Sandbox.exec takes a timeout but no AbortSignal, so a running command cannot be interrupted — only waited out or timed out. The turn budget works around this by abandoning the session rather than blocking on it.

为什么没有 App Store？Why is there no App Store build?

结构上就不可能。App Sandbox 不允许拉起 shell，也不允许连接 Docker socket。分发方式是签名的 DMG。 It is structurally impossible. App Sandbox forbids spawning shells and talking to the Docker socket. A signed DMG is the path.

白名单会管住 MCP 吗？Does the allowlist cover MCP?

默认不管。stdio MCP 跑在宿主机上，沙箱网络策略盖不住它们自己的出站。远程 MCP 只有 applyToMcp 打开时才受同一份名单约束。挡住一个服务的网页，并不等于挡住它的 MCP，反过来也一样。 Not by default. stdio MCP servers run on the host, so the sandbox network policy does not cover their own outbound traffic. Remote MCP is held to the same list only when applyToMcp is set. Blocking a service's website does not block its MCP server, and the reverse is also true.

提示词能把 Bot 打开到完全权限吗？Can a prompt switch a bot to full?

不能。规则只会更严，不会更松，所以写进提示词里的「规则」到不了完全权限。full 是另一条代码路径，只有人可以打开；打开之后，审批门整个旁路。 No. Rules may only tighten, never loosen, so a prompt cannot reach full. full is a separate path that only a person can turn on, and it bypasses the approval gate entirely.
